# AURA

### Описание
Интерактивное приложение с визуальными эффектами, сменой обоев, звуковым сопровождением и всплывающими окнами текстов песни.

### Исходный код
- Папка `src/` содержит полный исходный код проекта на C# (`Program.cs`, `MakeIcon.cs`).
- Скрипт `build.bat` для автоматической локальной сборки через встроенный компилятор `.NET Framework` (`csc.exe`).

### Релиз
Готовый исполняемый файл `AURA.exe` со всеми вшитыми ресурсами доступен во вкладке [Releases](https://github.com/shisno2/AURA/releases).
